# Режим g1_extmic: петличка в роботе, обработка на ноутбуке

Петличка через USB-звуковую карту подключается к Jetson робота. На Jetson работает
`jetson_mic_bridge.py`: он шлёт звук с петлички на ноутбук и проигрывает ответы
ассистента через динамик робота. STT, LLM и TTS работают на ноутбуке.

```
петличка → USB-звуковая карта → Jetson (jetson_mic_bridge.py)
        ── UDP 5556, PCM 16 кГц ──►  ноутбук (VAD → Whisper → LLM → TTS)
        ◄── TCP 5557, WAV ────────   ответ → g1_audio_play → динамик робота
```

Обе связи открывает ноутбук, поэтому файрвол на ноутбуке не мешает, а Jetson не нужно
знать IP ноутбука. Всё подписано общим ключом (HMAC-SHA256): чужое устройство в той же
Wi-Fi не может ни слушать петличку, ни играть звук через робота.

## Запуск (на ноутбуке, в папке KuzmichAI)

1. Подключите петличку к Jetson через **активную** USB-звуковую карту (с чипом).
   Пассивный переходник mini-jack → Type-C работать не будет.

2. Скопируйте мост на робота и запустите его. Пароль SSH спросят один раз:
   ```bash
   ./deploy_jetson_bridge.sh unitree@192.168.1.103
   ```
   Скрипт покажет найденные на роботе устройства записи и лог моста. Убедитесь, что там
   `Using USB capture device ...`. При первом запуске он сам создаст ключ
   `~/.config/kuzmich/bridge_token` и скопирует его на робота.

3. Запустите ассистента:
   ```bash
   VOICE_ENGINE_AUDIO=g1_extmic VOICE_ENGINE_ROBOT_IP=192.168.1.103 ./start.sh
   ```
   В логе должно появиться `Audio mode: G1_EXTMIC ...` и
   `External mic: receiving audio from ...`.

Чтобы режим включался без переменной, поменяйте в `start.sh` значение по умолчанию:
`export VOICE_ENGINE_AUDIO="${VOICE_ENGINE_AUDIO:-g1_extmic}"`.

## Если что-то не так

| Симптом | Что сделать |
|---|---|
| `No USB capture card found` в логе моста | Посмотрите устройства и укажите нужное: `./deploy_jetson_bridge.sh unitree@<ip> --device plughw:2,0` |
| `External mic: no audio from bridge ...` | Мост не запущен или IP не тот. Лог на роботе: `ssh unitree@<ip> cat /tmp/kuzmich_mic_bridge.log` |
| `dropped ... unauthenticated/stale packets` / `authentication failed` | Ключи не совпадают: ещё раз запустите `./deploy_jetson_bridge.sh` с этого ноутбука |
| Звук с петлички есть, а робот молчит | Проверьте в логе моста строку `player: ...` (должен быть `g1_audio_play`) и ошибки `player rc=` |
| Робот говорит, но не слышит | Проверьте петличку на Jetson: `arecord -D plughw:2,0 -f S16_LE -r 16000 -c 1 -d 5 /tmp/t.wav && aplay /tmp/t.wav` |
| На Jetson включён файрвол | Откройте UDP 5556 и TCP 5557 |

Остановить мост: `./deploy_jetson_bridge.sh unitree@<ip> --stop`.

## Настройки (переменные окружения, значения по умолчанию в start.sh)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `VOICE_ENGINE_AUDIO` | `local` | `g1_extmic` включает этот режим |
| `VOICE_ENGINE_BRIDGE_HOST` | `VOICE_ENGINE_ROBOT_IP` | адрес Jetson с мостом |
| `VOICE_ENGINE_BRIDGE_MIC_PORT` / `_PLAY_PORT` | `5556` / `5557` | порты моста |
| `VOICE_ENGINE_EXTMIC_PLAYER` | `bridge` | куда выводить звук: `bridge` (динамик робота через мост), `g1` (DDS, как в режиме g1; нужны `unitree_sdk2py` и кабель в сеть 192.168.123.x), `local` (динамики ноутбука, удобно для проверки петлички) |
| `VOICE_ENGINE_BRIDGE_TOKEN_FILE` | `~/.config/kuzmich/bridge_token` | файл ключа |

Параметры моста: `python3 jetson_mic_bridge.py --help` (устройство, порты, громкость,
интерфейс для `g1_audio_play`, своя команда плеера).

## Что проверено, а что нет

Проверено без робота (мост на втором ноутбуке вместо Jetson):
- протокол: звук, воспроизведение, отказ при чужом ключе, подделанных и повторно
  отправленных пакетах, мусорных и огромных запросах; мост переживает всё это;
- полный диалог: фраза в «петличку» → распознавание → ответ LLM → проигрывание через мост;
- работа между двумя машинами по Wi-Fi с включённым файрволом на «ноутбуке»;
- захват с настоящего микрофона через `arecord`, автовыбор USB-карты, Python 3.8;
- режимы `local` и `g1` работают как раньше.

Не проверено, потому что не было робота: настоящий `g1_audio_play` на Jetson, конкретная
USB-звуковая карта и петличка, сеть робота.
